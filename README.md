# شبكتك (Shabaktak)

تطبيق أندرويد (Kotlin) لإدارة أجهزة **MikroTik RouterOS** وشبكات الهوتسبوت وكروت الإنترنت مباشرة من الهاتف، عبر **RouterOS API**، دون الحاجة إلى سيرفر أو PHP أو متصفح.

**تحميل آخر نسخة:**
[shabaktak.apk](https://github.com/A282424/shabaktak-app/releases/latest/download/shabaktak.apk)

> بعد التنزيل اسمح بتثبيت التطبيقات من مصدر خارجي على هاتفك. إذا ظهر خطأ «تتعارض مع حزمة حالية» فاحذف النسخة القديمة ثم ثبّت الجديدة (يحدث عند اختلاف توقيع النسخة المثبّتة).

---

## ✅ المزايا

### لوحة التحكم
- فتح فوري للراوتر: تظهر آخر الأرقام المحفوظة مباشرة.
- **بث حيّ** للمعالج والذاكرة وسرعة التنزيل والرفع، مع تحذير ارتفاع المعالج (كهرماني من 60%، أحمر من 80%).
- عدد المتصلين الآن، وعدد الكروت، وعدد الباقات، ومبيعات اليوم مع مقارنة بأمس.
- بحث شامل عن مستخدم أو كرت أو جهاز.
- دعم أكثر من راوتر والتبديل بينها.

### الهوتسبوت والكروت
- إدارة الكروت: عرض، بحث، إضافة، تعديل، حذف، وتفعيل/تعطيل.
- **توليد دفعات كروت** مع إظهار المتبقي من كل دفعة.
- **الباقات (Profiles):** حقل مستقل لسرعة التنزيل وآخر لسرعة الرفع بوحدات K/M/G، ومدة الجلسة وعدد الأجهزة.
- **قوالب الكروت** ومصمّم مرئي للكرت، وطباعة ومشاركة الكروت.
- **المتصلون الآن** مع التحكم بالجلسات.
- **تقارير المبيعات** برسوم بيانية.
- سجل الهوتسبوت، واستثناء الأجهزة (Bypass)، ومصمّم صفحة تسجيل الدخول.

### الشبكة
- **عقود DHCP** و**عناوين IP** و**الواجهات** و**المسارات** بتحكم كامل.
- **جدار الحماية:** قواعد Filter وNAT وMangle مع تفعيل/تعطيل وترتيب ونسخ وتصفير العدادات.
- 🔒 **منع مشاركة الإنترنت** (هوتسبوت/بلوتوث) من هواتف المشتركين.
- 🛰 **حماية ستارلينك:** تمنع مشتركي الكروت من الوصول إلى الطبق وإعادة تمهيده من تطبيق Starlink.
- مراقبة الترافيك الحية ومراقبة الهوائيات.

### الصيانة والأمان
- **برمجة الراوتر** خطوة بخطوة مع تطبيق كل خطوة فور «التالي».
- **فحص الأمان** و**فحص المعالج** (تشخيص أسباب الحمل).
- **الاستهلاك والتنبيهات.**
- المهام المجدولة، والنسخ الاحتياطي، وإعادة تشغيل الراوتر.
- **شبكة أمان:** نسخة احتياطية قبل أي حذف مع زر **تراجع**.
- أدوار وصلاحيات للمستخدمين، وقفل للتطبيق.

## ⚙️ المتطلبات

- أندرويد 8.0 أو أحدث.
- راوتر MikroTik يعمل بـ RouterOS 6.43 أو أحدث (جُرّب على 7.x).
- خدمة **API** مفعّلة على الراوتر (المنفذ الافتراضي 8728):
  ```
  /ip service enable api
  ```
- يُنصح بإنشاء مستخدم مخصص للتطبيق، وبحصر وصول API على شبكتك الداخلية فقط.

## 🛠 بناء التطبيق بنفسك

### من Termux
```
cd ~/shabaktak/NetControlMikrotik
./gradlew assembleDebug
cp app/build/outputs/apk/debug/app-debug.apk ~/storage/downloads/shabaktak.apk
```

### نسخة موقّعة (release)
أنشئ ملف `keystore.properties` في جذر المشروع:
```
storeFile=/path/to/shabaktak-release.jks
storePassword=****
keyAlias=shabaktak
keyPassword=****
```
ثم:
```
./gradlew assembleRelease
```
الناتج: `app/build/outputs/apk/release/app-release.apk`

> ⚠️ **لا ترفع** `keystore.properties` ولا ملف `*.jks` إلى المستودع أبداً، وأضفهما إلى `.gitignore`. احتفظ بنسخة احتياطية من المفتاح، فإذا فُقد لن تستطيع تحديث النسخة المثبّتة عند المستخدمين.

### من Android Studio
1. افتح مجلد المشروع، واضغط **Trust Project**، وانتظر انتهاء **Gradle Sync**.
2. من القائمة: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
3. ستجد الملف في `app/build/outputs/apk/`.

## 🧱 البنية التقنية

- Kotlin، وبدون مكتبات ثقيلة: عميل RouterOS API مكتوب داخلياً (`MikrotikApiClient`).
- بث حيّ عبر أمر واحد مستمر (`/system/resource/print =interval=1`) بدل الاستعلام المتكرر.
- كل ميزة جديدة تُضاف بسهولة عبر أمر API جديد.
- اسم الحزمة: `com.netcontrol.mikrotik`
